# B 端后台与经营分析知识

## B 端后台定位

B 端后台用于维护电影购票系统的基础业务数据，并为 Agent 提供可靠的数据来源。C 端智能体负责购票体验，B 端后台负责数据管理和运营管理。

## B 端核心模块

### 电影管理

管理员可以新增、编辑、下架电影。

字段建议：

- 电影名称。
- 类型。
- 时长。
- 评分。
- 海报。
- 简介。
- 上映状态。
- 标签。

### 影院管理

管理员可以维护影院信息。

字段建议：

- 影院名称。
- 地址。
- 经纬度。
- 服务设施。
- 联系方式。
- 营业状态。

### 影厅管理

管理员可以维护影厅和座位布局。

字段建议：

- 影院 ID。
- 影厅名称。
- 影厅类型。
- 行数。
- 列数。
- 座位布局。

### 排片管理

管理员可以创建电影场次。

字段建议：

- 电影。
- 影院。
- 影厅。
- 开始时间。
- 结束时间。
- 票价。
- 影厅类型。
- 座位库存。

排片规则：

- 同一影厅同一时间不能排两个场次。
- 场次时间不能早于当前时间。
- 结束时间应根据电影时长和清场时间计算。
- 已有订单的场次不能随意删除。

### 订单管理

管理员可以查看订单列表和订单详情。

字段建议：

- 订单号。
- 用户。
- 电影。
- 影院。
- 场次。
- 座位。
- 金额。
- 状态。
- 创建时间。
- 支付时间。

## 经营分析

B 端可以提供简单看板：

- 今日订单数。
- 今日票房。
- 热卖电影排行。
- 热门影院排行。
- 热门时间段。
- 上座率。
- 退款数。

## B 端 Agent 问答

管理员可以询问：

- 今天哪个电影卖得最好？
- 哪个时间段订单最多？
- 哪个影院上座率最高？
- 明天 IMAX 场次够不够？
- 哪些场次快售罄了？

Agent 应调用后端统计接口，而不是只查 RAG。RAG 可用于解释指标含义。

## 指标解释

### 票房

票房是已支付订单的实付金额总和。未支付、取消和退款订单不应计入票房。

### 上座率

上座率 = 已售座位数 / 总可售座位数。

### 热卖电影

可按订单数或票房排序。答复时应说明排序口径。

### 热门时间段

可以按场次开始时间划分上午、下午、晚上、深夜，也可以按小时聚合。

## B 端和 Agent 的关系

B 端维护的数据越完整，Agent 推荐越准确。例如电影标签、影院距离、座位布局、价格规则、优惠信息都会影响 Agent 的推荐效果。
